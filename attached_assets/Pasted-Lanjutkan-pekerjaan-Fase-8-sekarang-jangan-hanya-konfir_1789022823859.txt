kerjakan (Arsip, Keuangan, Laporan, Pengeluaran, Barcode), lalu:

   sumber data yang sama — jangan biarkan dua implementasi terpisah.
2. Tambahkan info filter (layanan, batch, tanggal, status, kasir, waktu
   export) di header semua file export.
3. Format nominal konsisten (Rp + pemisah ribuan), berat maksimal 2 desimal,

4. PDF Cargo: lebarkan kolom "Jenis Barang" + aktifkan text wrapping supaya
   teks ≥60 karakter tidak terpotong.
5. Header tabel berulang otomatis di tiap halaman PDF; baris tidak boleh
   terpotong antar halaman.
6. Footer PDF: nomor halaman, waktu export, nama user yang export.
